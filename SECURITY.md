# Security

Report suspected vulnerabilities privately to [hello@probie.dev](mailto:hello@probie.dev)
with the subject **Probie JavaScript SDK security report**. Do not open a public
issue containing exploit details or sensitive data.

Include the affected SDK version, a description, reproduction steps, impact, and
any proposed fix. Use a minimal test project and synthetic data.

Security fixes target the latest SDK release. This project does not currently
promise a response SLA, paid bounty, or support window for older 0.x releases.

For details about collected data, see [data collection](docs/data-collection.md).
